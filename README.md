# Attroupe

> *Attrouper les potes.* Organisateur auto-hébergé pour groupes d'amis : planning commun,
> soirées et sorties, listes de courses, dépenses partagées, albums photos.
>
> Nom de code interne : **ACB**. V1 implémentée et en pré-production sur `beta.attroupe.fr` —
> voir [`DOCUMENTATION.md`](DOCUMENTATION.md) et le
> [dossier de conception](Dossier%20de%20conception/).
